# La interpretación cromosomática

Ejemplos de configuraciones cromosómicas sexuales presentados para cuestionar una lectura estrictamente binaria del sexo cromosómico.

- XX y XY son configuraciones frecuentes, no las únicas.
- Ejemplos: 47,XXX; 47,XXY; 47,XYY; 45,X; y mosaicismos.
- No usar los cromosomas para inferir identidad de género, anatomía o experiencias de una persona.

Fuentes de consulta: MedlinePlus Genetics (trisomía X, Turner y cromosoma X) y National Human Genome Research Institute (cariotipo y cromosomas sexuales).
