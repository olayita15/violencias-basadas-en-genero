# Variaciones cromosómicas: no hay una lista cerrada

Esta diapositiva amplía los ejemplos numéricos de cromosomas sexuales:

- 48,XXXX; 48,XXXY; 48,XXYY; 48,XYYY.
- 49,XXXXX; 49,XXXXY.
- Mosaicismos y cambios estructurales: pérdidas, duplicaciones, anillos y translocaciones.

Nota de rigor: `45,X` es la notación citogenética preferida para la expresión informal “X0”. No hay una lista cerrada de configuraciones posibles, y los cromosomas no permiten inferir identidad de género, anatomía ni vivencias.

Fuentes: MedlinePlus Genetics, páginas “X chromosome”, “Y chromosome”, 48,XXYY syndrome y 49,XXXXY syndrome.
